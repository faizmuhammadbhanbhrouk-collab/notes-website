# Notes Website

Faiz ke HTML, CSS aur JavaScript notes — ek hi website me.

## Kya hai is me

- **3 tabs:** HTML (19 topics), CSS (32 topics), JavaScript (31 topics)
- **Topic Filter:** upar search box aur dropdown — topic chunno, PDF us ke page par khul jayegi
- **PDF viewer:** har tab me us subject ki asal PDF khulti hai, Pichla / Agla page buttons ke sath
- **PDF Download:** har tab par us ki PDF download karne ka button
- **Light theme**, orange #ff5100 accent, **sirf Roman English**, mobile responsive

## Files

- `index.html` — poori website (ek hi file)
- `html-notes.pdf` — HTML Notes, 35 pages
- `css-notes.pdf` — CSS Notes, 42 pages
- `javascript-notes.pdf` — JavaScript Notes, 33 pages

## Live kaise karein (GitHub Pages)

1. Repo ke **Settings** me jao
2. Left side **Pages** kholo
3. Source me **Deploy from a branch** chunno, branch **main** aur folder **/ (root)** rakho
4. Save karo — kuch der me site `https://<username>.github.io/notes-website/` par live ho jayegi
